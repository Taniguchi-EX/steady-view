# Steady View

酔いやすい人向けのMinecraft（Java版）クライアントModです。オンライン公園のメンバーのκeenさん向けに作りました。

- マウスを動かしても視点は動きません。視点はキーボードで45度ずつ（設定画面で5〜90度に変更可）、アニメーションなしで瞬時に切り替わります
- マウスカーソルを画面の端に押し当てると、その方向に視点が45度切り替わります（設定で、なめらかに回る方式に変えたり、オフにしたりできます）
- 攻撃・採掘・ブロックの設置・使用は、画面中央の照準ではなく、マウスカーソルが指している物に対して行います。弓や雪玉等もカーソルの方向へ飛びます
- 画面の揺れ・視野の変化など、酔いの原因になるMinecraftの設定を、初回起動時に自動でオフにします（「自動で変わるMinecraftの設定」参照）
- 自分のPCにだけ入れるModです。サーバ側には何も入れる必要がなく、Modを入れていないサーバでもそのまま使えます

## 前提

- Minecraft Java版 26.3
- Fabric Loader 0.19.5以上
- Fabric API（26.3向け。0.161.0+26.3で動作確認済み）
- Java 25（Modrinth Appや公式ランチャーを使う場合は自動で用意されるため、別途インストールする必要はありません）

ほかのModとの併用は確認していません。特に、Controlify等の視点操作を変えるModとは一緒に使わないでください。

### Linuxで使う場合の注意

- 動作確認はWindowsでしか行っていません。Mod自体はJavaだけで書いているため、Linuxでもそのまま動く想定です
- カーソルをウィンドウの外に出さない機能（`confineCursor`）は、デスクトップ環境（Wayland/X11）によって効かないことや、動きが変わることがあります。カーソルの動きがおかしい場合は、設定ファイルで`confineCursor=false`にしてください（ほかの機能はそのまま使えます）

## 導入方法

配布されたjar（`steadyview-<バージョン>.jar`）を、Fabric 26.3の環境の`mods`フォルダに入れます。おすすめはModrinth Appを使う方法です。

### Modrinth Appを使う場合（おすすめ）

1. [Modrinth App](https://modrinth.com/app)をインストールし、Microsoftアカウントでログインする
2. 新しいインスタンス（プロファイル）を作る。ゲームのバージョンは`26.3`、ローダーは`Fabric`を選ぶ
3. 作ったインスタンスに、Modの検索から「Fabric API」を追加する
4. インスタンスのフォルダを開き、`mods`フォルダに`steadyview-<バージョン>.jar`を入れる
5. インスタンスを起動する

Modパック（`steadyview-<バージョン>.mrpack`）を受け取った場合は、Modrinth Appでそのファイルを読み込む（インスタンスの作成画面で「ファイルから読み込む」を選ぶ、またはファイルをModrinth Appにドラッグする）だけで2〜4が済みます。パックには、Fabric 26.3、Fabric API、Mod Menu（とそれが必要とするText Placeholder API）、Steady Viewが入っています。

### 公式ランチャーを使う場合

1. [Fabricのインストーラー](https://fabricmc.net/use/installer/)を実行し、「Client」でMinecraftのバージョン`26.3`を選んでインストールする
2. [ModrinthのFabric APIのページ](https://modrinth.com/mod/fabric-api)から、26.3向けのjarをダウンロードする
3. `%APPDATA%\.minecraft\mods`フォルダ（なければ作る）に、Fabric APIのjarと`steadyview-<バージョン>.jar`を入れる
4. 公式ランチャーで起動構成「fabric-loader-26.3」を選んで起動する

### 導入できたかの確認

ワールドに入ると、マウスカーソルが表示されたままになり、マウスを動かしても視点が動きません。
F8を押すと画面下に「Steady View: 無効」と表示され、通常の操作に戻ります。もう一度F8を押すと有効に戻ります。

## 使い方

### キー割り当て（既定）

- 左に回る: Z
- 右に回る: X
- 上を向く: R
- 下を向く: V
- 水平に戻す: B
- Modの有効・無効: F8
- 設定画面を開く: F7

「設定 > 操作設定 > キー割り当て」の「Steady View」の欄で変更できます。

- 1回で回る角度は、既定で45度です（設定画面で変えられます）。45度のとき、上下は真上・斜め上・水平・斜め下・真下の5段階です
- XはクリエイティブのXを押しながら数字キーを押す操作と、V・BはF3を押しながらの操作と同じキーです。普段の操作には影響しません

### マウスの操作

- 左クリック: カーソルの指す物を攻撃する・ブロックを掘る（押し続けて採掘）
- 右クリック: カーソルの指す場所にブロックを置く・ドアやチェスト等を使う・村人等に話しかける
- ホイールクリック: カーソルの指すブロックを選ぶ
- 狙っているブロックには、通常どおり黒い枠線が出ます。届く距離も通常と同じです

### 画面の端での視点の切り替え

マウスカーソルを画面の端まで動かすと、その方向に視点が45度（設定画面の「1回で回る角度」）切り替わります。

- 左端・右端で左右に、上端・下端で上下に切り替わります。角では両方に切り替わります
- 切り替わった後、カーソルは「切り替わる前に指していた方向」が新しい画面で映る位置へ移ります。狙っていた物を指したまま、視点だけが変わります
- 続けて回りたいときは、もう一度カーソルを端まで動かします（端に置いたままにしても、続けては回りません）
- 真上・真下を向いているときは、それ以上上下には切り替わりません
- 設定ファイルの`turnAtScreenEdge`を`false`にすると、この機能をオフにできます

#### なめらかに回る方式

設定ファイルの`edgeTurnMode`を変えると、45度ずつ切り替える代わりに、画面の端で視点がなめらかに回るようになります。

- `push`: カーソルを端まで動かした後、さらにマウスを外側へ動かした分だけ回ります。マウスを止めると視点も止まります。カーソルは端から少し内側（16ドット）の位置で止まって見えます。回る速さと上下・左右の反転は、Minecraftの「マウス設定」の感度・反転に従います
- `scroll`: カーソルが端にある間、一定の速さで回り続けます。速さは`edgeScrollSpeed`（1秒に回る角度。既定は90）で変えられます

どちらの方式でも、次のようになります。

- 左端・右端で左右に、上端・下端で上下に回ります。角では両方に回ります
- 向きは45度単位にそろいません。キー（Z・X・R・V）では、今の向きから「1回で回る角度」だけ回ります。B（水平に戻す）では、左右の向きはそのままで上下だけ水平に戻ります
- `confineCursor`を`false`にしている場合、カーソルがウィンドウの外に出ると回らなくなります（`push`）。`push`・`scroll`は`confineCursor=true`（既定）で使ってください

### 乗り物に乗っているとき

通常のMinecraftでは、ボートが曲がると視点も一緒に回り、ボートに乗った瞬間にはボートの向きに視点が合わせられます（トロッコも設定によってカーブで回ります）。
このModでは、ボート・トロッコ・馬等に乗っている間、こうした自動的な視点の変更を打ち消し、視点を変えるのはキー操作と画面の端での切り替えだけにします。

- 乗り物だけが曲がり、視点はそのままです。キーや画面の端での切り替えは、乗っている間も通常どおり使えます
- 設定ファイルの`keepViewWhileRiding`を`false`にすると、通常のMinecraftと同じく乗り物に合わせて視点が変わります。その場合も、視点は「1回で回る角度」の単位で切り替わります（45度なら、乗り物が22.5度以上曲がるごとに45度）。`edgeTurnMode`が`push`・`scroll`のときは、45度単位にそろえず、乗り物に合わせてなめらかに変わります

### 飛ばすアイテム

弓・クロスボウ・トライデント・雪玉・卵・エンダーパール・投げるポーション・釣り竿等は、マウスカーソルが指している点に向かって飛びます。

- 使う（投げる・放す）瞬間だけ、サーバに送るプレイヤーの向きをカーソルの指す点へ向けます。画面の視点は動きません
- 弓・トライデントは、放した瞬間のカーソルの位置で狙いが決まります
- 狙うのはカーソルの指す点への直線です。遠くを狙うときは、通常のMinecraftと同じく、重力で落ちる分だけ上を狙ってください
- 右クリックで使うアイテムのうち、プレイヤーの向きで対象を決めるもの（バケツで水をくむ等）も、カーソルの方向で決まります
- 設定ファイルの`aimItemsAtCursor`を`false`にすると、通常どおり視点の正面（画面中央）へ飛びます

## 自動で変わるMinecraftの設定

画面の揺れによる酔いを減らすため、Modを入れて初めて起動したときに、Minecraftの「ビデオ設定」「アクセシビリティ設定…」の以下の項目を自動で変えます。

- 「画面の揺れ」をオフ
- 「視野の変化」を0%
- 「画面の歪み」を0%
- 「被ダメージ時の画面の揺れ」を0%
- 「暗闇の脈動」を0%
- 「空の明滅の非表示」をオン

変えるのは初回の1回だけです。その後に自分で設定を変えた場合は、その値がそのまま使われます。
もう一度おすすめの値に戻したいときは、設定ファイルの`recommendedSettingsApplied`を`false`にしてから起動してください。

また、必要に応じて「視野」を広め（80〜90程度）にすると、45度ずつ回ったときに前後のつながりが分かりやすくなります（こちらは自動では変えません）。

## 設定画面

F7キー、またはMod Menuの「Mod」一覧（タイトル画面・ゲームメニューの「Mod」ボタン）からSteady Viewを選ぶと、設定画面が開きます。

- 1回で回る角度: キーと画面の端（`edgeTurnMode`が`step`のとき）で、1回に視点が回る角度です。視点はこの角度の単位でそろいます
  - スライダーで、5・6・9・10・15・18・30・45・90度から選べます（既定45度）
  - どの角度でも東西南北・水平・真上・真下をちょうど向けるよう、90の約数に限っています
  - `edgeTurnMode`が`push`・`scroll`のときも、キーではこの角度ずつ回ります
- 変更は、画面を閉じたときに設定ファイルに保存されます

配布しているModパック（.mrpack）にはMod Menuが入っています。Mod Menuがなくても、F7キーで設定画面を開けます。

## 設定ファイル

初回起動時に、`config/steadyview.properties`（インスタンスのフォルダの中）が作られます。テキストエディタで書き換え、Minecraftを再起動すると反映されます。

- `enabledOnStartup`: 起動時に有効にするか（既定`true`）
- `confineCursor`: ゲーム中、カーソルをウィンドウの外に出さないようにするか（既定`true`）
- `hideCrosshair`: 有効なとき、画面中央の照準を隠すか（既定`true`）
- `stepAngle`: 1回で回る角度（既定`45`）。5・6・9・10・15・18・30・45・90のどれか。それ以外の値は最も近い値になる。設定画面からも変えられる
- `turnAtScreenEdge`: カーソルを画面の端まで動かしたとき、その方向に視点を変えるか（既定`true`）
- `edgeTurnMode`: 画面の端での視点の変え方。`step`（45度ずつ切り替える）・`push`（押し込んだ分だけなめらかに回る）・`scroll`（端にある間、一定の速さで回る）のどれか（既定`step`）
- `edgeScrollSpeed`: `edgeTurnMode`が`scroll`のとき、1秒に回る角度（既定`90.0`）
- `keepViewWhileRiding`: 乗り物に乗っている間、乗り物による自動的な視点の変更を打ち消すか（既定`true`）
- `aimItemsAtCursor`: 弓・雪玉等の飛ばすアイテムを、カーソルの指す点へ飛ばすか（既定`true`）
- `recommendedSettingsApplied`: Minecraftの設定（上記「自動で変わるMinecraftの設定」）を変更済みか。初回起動時に`true`になる

## 開発

### 必要なもの

- JDK 25（開発PCでは`~/.jdks/jdk-25.0.4.1+1`にTemurin 25を置いている）
- Gradleは同梱のWrapper（`gradlew`）を使うため不要

### コマンド

```sh
export JAVA_HOME="$HOME/.jdks/jdk-25.0.4.1+1"
./gradlew build             # ビルドと単体テスト。jarは build/libs/steadyview-<バージョン>.jar
./gradlew runClient         # 開発用クライアントの起動（オフラインのプレイヤーになるため、online-modeのサーバには入れない）
./gradlew runClientGameTest # ゲーム内の自動テスト。Modなしの専用サーバでの動作確認も含む
```

- `runClientGameTest`は実際にゲームのウィンドウを開き、ワールドの作成・キーとマウスの操作・テスト用の専用サーバ（ポート25565）への接続を自動で行います。スクリーンショットは`build/run/clientGameTest/screenshots/`に保存されます
- `build.gradle`の`eula = true`で、テスト時にMinecraftのEULAに同意しています

### Modパック（.mrpack）の作成

```sh
./gradlew build
python tools/build_mrpack.py   # build/distributions/steadyview-<バージョン>.mrpack ができる
```

- Python 3.9以上が必要です（標準ライブラリだけを使います）
- Minecraft・Fabric Loader・Fabric APIのバージョンは`gradle.properties`の値に合わせます
- Fabric API・Mod Menu・Text Placeholder APIは、Modrinthのダウンロード先とハッシュだけをパックに書きます。Steady View本体はModrinthに公開していないため、jarをパックの`overrides/mods`に同梱します

### 構成

- `src/main`: マイクラに依存しない角度の計算（`AngleMath`）と、`fabric.mod.json`・言語ファイル
- `src/client`: Mod本体（キーの処理、カーソルからの狙いの計算、Mixin）
- `src/test`: 単体テスト（JUnit）
- `src/gametest`: ゲーム内の自動テスト（Fabric APIのクライアントゲームテスト）
